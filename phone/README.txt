星澜手机端 0.4.2 独立服务版

目标
====

这是独立实现的越狱 iPhone USB 投屏与控制服务，不包含鹰眼的代码、资源、私有协议或授权逻辑。架构上采用与成熟群控产品相同的进程隔离和多通道思路，但所有协议和实现均为本项目自行设计。

运行方式
========

1. 安装包把 xlstreamd 安装到 /var/jb/usr/libexec。
2. LaunchDaemon 以 root 身份独立运行，不依赖旧星澜或 TrollVNC 的 SpringBoard 插件。
3. 服务异常退出后由 launchd 自动拉起。
4. 手机重启并重新越狱后，服务会随越狱环境自动启动。

独立通道
========

1. 6202：IOSurface -> VTPixelTransferSession -> VideoToolbox H.264 视频。
2. 6203：二进制控制通道，支持触摸、Home、开屏、熄屏、多任务切换和关键帧请求。
3. 6204：状态与心跳通道，返回电量、在线状态、视频客户端数、丢帧和控制错误。
4. 6205：独立USB文件服务，保存文件并可把图片或视频提交到系统相册。
5. 6203 还支持 UTF-8 文字输入（剪贴板 + Command-V）以及回车、退格等 HID 按键。
6. 每条控制与状态消息都有固定头、版本、长度和序列号，避免文本粘包和误解析。

文件可见性
==========

文件服务以root运行，但保存目录和收到的文件会立即改为mobile用户所有。
服务启动时也会修复目录内旧文件的所有权和读取权限，确保系统“文件”App可以显示文件名和打开文件。

视频策略
========

1. CARenderServer 直接渲染到 IOSurface，不创建 CGImage 截图。
2. 三缓冲槽；编码器繁忙时丢弃新帧，不建立无限队列。
3. 电脑端不读取时主动断开该视频客户端，避免拖住手机界面进程。
4. 电脑重连或解码失步时可通过 6203 请求新的 H.264 关键帧。

构建
====

需要 Theos、iOS 15 SDK 和 arm64/arm64e 工具链。GitHub Actions 会分别生成 RootHide 和普通 Dopamine Rootless 两个 deb；不要把两个包混装到同一台手机。
