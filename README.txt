星澜 USB 原生群控新版

项目边界
========

这是独立的新项目。旧星澜目录、网页版本、TrollVNC版本和现有安装包均未修改、未删除。

当前目标
========

1. 支持发现最多60台已经安装 XLStream 的越狱 iPhone；每组10台，手动连接当前组进行投屏和控制。
2. 手机端改为独立 root LaunchDaemon：6202 视频、6203 控制、6204 状态/心跳、6205 文件传输，不再依赖旧 6000/6002/6003 链路。
3. Windows端画面只在内存里处理，不再逐帧写 JPEG 文件。
4. 每台设备只保留最新一帧，电脑显示跟不上时覆盖旧帧，避免延迟不断累积。
5. 视频超过3.5秒没有数据时自动重连；单台异常不影响其他手机。
6. Windows端固定使用已经通过十台测试的软件解码，不再启动实验性硬件探测子进程。
7. 小窗口复用同一个Tk图像缓冲区，避免十台画面持续创建GDI对象导致运行一段时间后卡顿。
8. 界面显示总帧率、CPU和内存，日志自动滚动。
9. 软件启动和USB扫描都不自动投屏；只有点击“连接本组”或单机“开始”才建立通道。“全部投屏”“全部停屏”当前仅保留界面按钮，不执行操作。
10. 点击“断开本组”或单机“停止”后，立即清除最新帧并关闭视频、控制和状态通道，软件本身继续运行。
11. 手机不会自动占分组位置；手动设置后按UDID永久保存组号、组内编号和自定义名称，拔线、乱序重插或重开软件都不会改变位置。
12. 顶部“全部开屏”和“全部熄屏”只控制当前USB在线手机，不会自动开始投屏。
13. 分组设置中的“识别选中手机”会让对应实体手机先熄屏、再开屏一次，方便把UDID和现场手机一一对应。
14. “切换窗口”与旧版一致，打开当前主控或已勾选同步手机的iPhone多任务切换界面。
15. 每台小窗口带独立勾选；全选和全反只改变当前组勾选，同步开关独立控制是否广播主控操作。
16. “文件传输”可把电脑文件通过USB直接发送到当前主控或已勾选同步手机；图片和视频可选择导入系统“照片”。

启动方法
========

源码方式可双击“启动新版星澜.cmd”；正式交付直接双击“星澜.exe”。手机只进入待机列表，不会自动投屏。
选择分组后点击“连接本组”，或点击某台手机右侧的“开始”；不使用时点击“断开本组”或单机“停止”。

固定分组
========

点击顶部“分组设置”，选择一台手机后填写名称、分组和组内编号，再点“保存当前手机”。
不知道UDID对应哪台实体手机时，选中列表中的手机后点击“识别选中手机”；现场对应手机会先熄屏、再开屏一次。
USB在线但尚未分组的手机会显示“未设置”，不会自动占用任何编号。
配置保存在 config\device_groups.json。一个组内编号只能绑定一台手机，重复位置会被拦截。
某台手机USB离线时会留在原来的格子并显示“USB未连接”，其他手机不会自动补位。
开屏与熄屏
============

顶部“全部开屏”和“全部熄屏”对软件当前识别到的全部USB手机生效，不受当前分组和投屏状态限制。
软件发现手机后会在后台提前保持一条轻量级USB控制通道；点击按钮时只通过6000端口发送一次
旧版原始14/15指令，不再临时同时建立60条连接，不确认、不重发，也不会启动视频通道。

同步群控
========

每台小窗口右侧的勾选框决定它是否接收同步操作。“全选”勾选当前组全部手机，“全反”取消当前组全部勾选。
“同步群控”关闭时，“返回主屏”和“切换窗口”只控制当前主控；开启时控制当前组内已勾选且已经投屏的手机。
左侧小窗口始终只操作单台手机；只有右侧主控大画面的点击和拖动会按勾选状态同步。

文件传输
========

连接当前组后点击“文件传输”，可选择单个文件或完整文件夹；文件夹会保留名称、子目录和空目录，发送到当前组已连接投屏的手机（最多10台）。
图片或视频可勾选“传完后导入系统照片”。传输走新版手机端6205文件服务，不依赖旧星澜插件，也不会启动额外的视频通道。

运行日志
========

日志保存在 logs\星澜新版运行.log。单个文件最大5MB，最多保留3个历史文件。
程序每10秒记录一次投屏设备数、总帧率、CPU、内存、重连次数和最大画面延迟。

解码模式
========

程序默认使用软件解码。十台测试中总帧率约119、CPU占用很低，而且内存明显比当前
D3D11VA下载到Tk画面的路径稳定。

精简正式版不再包含实验性硬件解码入口，避免误开后引起原生内存增长。
