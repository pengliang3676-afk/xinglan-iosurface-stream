星澜 USB 原生群控新版（第一阶段）

项目边界
========

这是独立的新项目。旧星澜目录、网页版本、TrollVNC版本和现有安装包均未修改、未删除。

当前目标
========

1. 先支持一台已经安装星澜 USBMirror 测试插件的越狱 iPhone。
2. 只连接新端口6202的IOSurface/XLV3视频，不再回退旧6002。端口6000暂时接收触摸。
3. Windows端画面只在内存里处理，不再逐帧写 JPEG 文件。
4. 每台设备只保留最新一帧，电脑显示跟不上时覆盖旧帧，避免延迟不断累积。
5. 视频超过3.5秒没有数据时自动重连；单台异常不影响其他手机。
6. 第一阶段界面最多连接10台，后续单机稳定后再扩大。
7. 界面显示总帧率、CPU、内存和重连次数，日志自动滚动，避免无限增大。

启动方法
========

双击“运行环境检查.cmd”，确认依赖正常并能识别USB手机。
双击“启动新版星澜.cmd”打开新版测试界面。

真机测试准备
============

1. 先只连接一台手机。
2. 手机已越狱，并安装我们自己的 USBMirror H.264 测试插件。
3. 手机与电脑已经点过“信任”。
4. 先验证画面、点击、滑动和自动重连，再接入10台。

验收顺序
========

单机连续运行30分钟 -> 单机连续运行24小时 -> 2台 -> 5台 -> 10台。
观察画面延迟、实际帧率、重连次数和电脑内存，任何一项持续上涨都不进入下一阶段。

运行日志
========

日志保存在 logs\星澜新版运行.log。单个文件最大5MB，最多保留3个历史文件。
压力测试期间每10秒记录一次设备数、总帧率、CPU、内存、重连次数和最大画面延迟。
